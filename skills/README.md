## Qué cambia frente a v1
- **Paso 0 automático:** lee Tablero, Hoja de precios, marca y registro antes de preguntar.
- **12 recetas probadas** (`references/recetas.md`) sacadas de los virales reales (Blevins 1,02 M, Vidaurre 714 mil, Adivina la bicicleta, charla "este CRACK", Nunca pongas tu bici AL REVÉS 102 mil) y del caso Rockintor.
- **Reglas nuevas con evidencia:** una variación del mismo material por semana (las demás como Trial Reels); copy propio por pieza; BOFU se mide por DMs; CTA dentro del remate y sin despedida (alineado con editor-mamba); cada dato con fuente.
- **Registro de aprendizajes** en 3 columnas que se alimenta en cada uso con la frase literal de Otto.
- Entregable ampliado: dónde y cuándo publicar + lista de datos verificados.

- **Memoria de Otto** (`references/memoria.md`): reglas permanentes, casos aprobados, rechazos con su frase literal, marcas, flujo de kit para Code y datos vigentes. Manda sobre el resto.
- **Guía de voz** (`references/voz-otto.md`): jerga, trato tú/usted, mecánicas de humor y prueba de voz, sacadas de 8 guiones manuales de Otto (que no son plantilla).
- 3 ganchos alternativos en cada entregable (los extra sirven como Trial Reels).
- Modo remix (solo material existente), Otto como único protagonista, entrega de kit EDIT_SPEC.md para Code (sin renders).
